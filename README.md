# Operating Systems - Laboratory Works

This repository contains laboratory assignments completed as part of my university coursework in operating systems. The assignments cover both Windows and Linux, providing practical experience with different operating environments, system tools, and operating system fundamentals.

## Repository Structure

- **Windows** - Laboratory assignments focused on working with the Windows operating system, its tools, system configuration, and administration fundamentals.
- **Linux** - Laboratory assignments focused on the Linux operating system, command-line operations, file system management, and basic system administration.

## Skills and Knowledge

These laboratory works have helped me develop practical skills in working with Windows and Linux environments, navigating file systems, using system utilities, executing commands, and understanding the fundamental principles of operating systems.

This repository is part of my academic portfolio and demonstrates the knowledge and practical experience I have gained through university coursework in operating systems.
